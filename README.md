# Stackoverhack — WOBBLE Flaky Test Platform

## Repository Layout
- **`frontend/`**: Next.js 16 frontend application (React 19, TypeScript, Three.js 3D Phase-Space variance topology, GSAP motion engineering, Tailwind CSS).
- **`backend/`**: Backend services and Django REST Framework API adapters.

## Getting Started

### Running the Frontend
From the repository root:
```bash
npm run dev
```

Or directly inside the frontend folder:
```bash
cd frontend
npm run dev
```

### Production Build
```bash
npm run build
```
